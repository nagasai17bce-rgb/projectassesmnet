# Naga Sai — AI Systems Engineering Lab

A portfolio monorepo containing 25+ production-shaped projects across inference, RAG, agent orchestration, MCP/tool systems, evaluation, observability and data platforms.

## Focus

Inference routing • adaptive batching • semantic caching • fallback control • token budgets • hybrid RAG • enterprise document retrieval • MCP gateways • tool routing • orchestration • memory • evaluation • trace grading • CI quality gates • streaming • document intelligence • SQL analytics • data quality • incident analysis • fraud investigation • feature retrieval • code review • data migration • recommendation explanations.

## Engineering standard

Each project is intended to evolve toward typed contracts, tests, tracing, failure handling, evaluation datasets, Docker, CI/CD and reproducible load tests. No performance claim is presented without a benchmark.

The themes are grounded in public engineering patterns: Databricks examples cover model serving, RAG, MCP, memory, MLflow evaluation and production agent lifecycle; Google Cloud examples demonstrate agents combining RAG, tools and cloud data.
